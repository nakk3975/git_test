# git_test

> Git 실습 · 파일 변경·브랜치

Git 브랜치와 커밋, 파일 변경 흐름을 연습하기 위해 사용한 테스트 저장소입니다.

## 실습 내용

- 텍스트 파일 생성 및 수정
- 변경 사항 커밋
- 브랜치별 작업
- 파일 추가 이력 확인
- Git 저장소의 기본 버전 관리 흐름 연습

저장소에 포함된 간단한 텍스트 파일들은 Git 동작을 확인하기 위한 테스트 데이터입니다.

## 목적

실제 서비스 코드보다는 Git 사용법을 반복해서 연습하고 커밋 이력을 확인하기 위한 개인 실습 저장소입니다.
